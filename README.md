# Installation

## Install via pip from Git

```sh
pip install git+https://github.com/ARES-Digital-Hub/ARES-Cache.git
```

---

## Add as a Git Submodule

```sh
git submodule add https://github.com/ARES-Digital-Hub/ARES-Cache.git external/cache
git submodule update --init --recursive
```

This will add the repository as a submodule in the `external/ARES-Cache` directory. Adjust the path as needed.
